# Week 6 Capstone: Customer Churn Prediction and Segmentation

## Overview
End-to-end Data Science project covering cleaning, feature engineering, EDA, K-Means segmentation, supervised churn prediction, a neural-network MLP, evaluation, error analysis, and recommendations.

## Dataset
Download the public IBM Telco Customer Churn CSV:
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

Place `WA_Fn-UseC_-Telco-Customer-Churn.csv` beside the notebook.

## Files
- `Customer_Churn_Capstone_Week6.ipynb` — complete interactive workflow.
- `Week6_report.docx` — detailed report template.
- `README.md` — setup and run instructions.
- `outputs/` and `visualizations/` — created after notebook execution.

## Run
1. Download the dataset and place the CSV beside the notebook.
2. Open the notebook in Jupyter or Google Colab.
3. Run all cells.
4. Use generated files in `outputs/` and `visualizations/` to complete the report.

## Methods
- Cleaning and feature engineering with pandas
- EDA with Matplotlib and Seaborn
- K-Means clustering with elbow and silhouette diagnostics
- Logistic Regression and Random Forest
- MLP neural network with dropout, early stopping, and checkpointing
- Accuracy, precision, recall, F1, ROC-AUC, cross-validation, confusion matrix, ROC curves, permutation importance

## Important
Metrics are generated by executing the notebook and are not prefilled. Keep the test set reserved for final evaluation. Observed associations do not establish causation. The engineered customer-value field is a rough proxy, not true lifetime value.
